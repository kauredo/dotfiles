# Solo retro

One contributor in the window. This replaces the per-person section and the collaboration section. Write it as a personal engineering journal, in "you" throughout. No praise/growth split: fold both into the reflection prompts.

Sections, in order:

1. **Tweetable summary**: first person, may name a focus theme.
2. **What you shipped**: themes as in the main report.
3. **Focus analysis**: top directories, depth against breadth, steady against bursty cadence. Neutral on all three.
4. **Consistency and momentum**: active days out of possible days, streak, longest gap excluding weekends, comparison with the previous retro when step 4 allows.
5. **Reflection prompts**: 2-3 questions built from the data. Examples: repeated churn in one area, a feature with no test changes, a multi-day gap. Each is a question, never a judgment.

Done when all five are present and each prompt cites a number or file from the data.
