# Skills to suggest

These run only when I type them, so I forget they exist. When the situation in
the left column comes up, suggest the command in one line ("This looks like a
job for `/sweep`.") and carry on. Suggest once per situation; I decide whether
to run it.

| When this comes up | Suggest |
|---|---|
| A feature is about to be built end to end, through to a PR | `/ship` |
| The work is too big for one session and needs decisions tracked as tickets | `/wayfinder` |
| A small diff that could break something outside itself | `/blast-radius` |
| I name an existing feature to review, with no diff | `/feature-review` |
| The repo feels over-built, or I ask what could be deleted | `/code-audit` |
| Cleanup after a busy stretch, quality only | `/sweep` |
| Open Dependabot alerts or PRs | `/dependabot-review` |
| Starting the day, or asking what needs my attention in a repo | `/standup` |
| Resuming work, or asking where I left off | `/recall` |
| Another agent is running or just finished, and I want its work checked | `/agent-watchdog` |
| A decision needs answers from someone else | `/to-questionnaire` |
| Your last explanation lost me | `/wait-what` |
| Writing or reviewing docs, an RFC, a README or a spec | `/technical-writing` |
| A draft needs AI tells stripped, especially text I didn't write | `/unslop` |
| A project has no scripted way to prove its UI or CLI works | `/create-verification-skill` |
| That project's verification skill may be stale | `/maintain-verification-skill` |
| Screens are being designed on a Claude Design canvas | `/design-loop` |
| A running local app should be compared or edited visually in Design | `/visual-edit` |
| A change needs a demo video for a PR or a post | `/demo-video` |
| A project site is done and worth a launch video | `/brag` |
| A repo should end replies with a red, yellow or green status block | `/quick-recap` |
| I refer to something I just said or saw on screen, and Clips Rewind runs | `/rewind` |
